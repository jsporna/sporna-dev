# Python

Tworzę narzędzia automatyzujące operacje i integracje w Pythonie, koncentrując się na czytelności, testowalności 
i niezawodności. 

Buduję CLI i usługi (fastapi/flask) do obsługi workflow, integracji z AWS API (boto3), systemami ticketowymi, CMDB 
i monitoringu. 

Stosuję dobre praktyki: typowanie (mypy), testy (pytest, coverage), formatowanie i linting (black, ruff), 
CI/CD z publikacją pakietów (poetry/uv).
